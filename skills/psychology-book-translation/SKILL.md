# 心理学书籍精翻

把用户提供的英文心理学书籍 PDF 译成适合连续阅读的中文。保持作者的概念、论证、证据和不确定程度；清楚区分「已翻译」「已逐页核对」和「无法可靠辨认」。这是精翻流程，不宣称译稿无需人工终校即可出版。

## 开始一本书

1. 确认 PDF、输出目录、翻译范围及已有译稿。默认交付同一书籍目录中的 `中文阅读稿.md`、`全书术语表.md`、`翻译进度.md`、`逐页审校记录.md`。用户已有文件时先读取进度并续译，勿覆盖已完成内容。
2. 查看书名页、版权页、目录、章节和开头内容，记录作者、版本、主题、目标读者、主要理论、行文风格，以及 PDF 页码与印刷页码的对应关系。在 `翻译进度.md` 建页面结构清单，逐页标记章节、单双栏、图、表、公式、脚注、扫描页及可读性；不确定的结构标为待核。可用 OCR 时核对 OCR 与页面图像。裁切、缺页和识别不清须记录，不能猜补。
3. 有图片时，询问用户本书采用「英文原图＋中文对照说明」还是「中文重绘」，并沿用其已表达的选择。尚未得到选择时可继续独立的正文翻译，把图片标为待定；依赖图片才能理解的段落不得标成已完成。
4. 建立本书术语表：英文、选定中文、语境/所指、核对来源或理由、状态。可按需查看[精选术语参考](references/seed-glossary.md)，但它只提供候选。优先核对原书的定义和局部用法，再参考相关分支的专业词典、教材或论文；有分歧时说明取舍。查不到可靠依据时保留英文并标为暂定。
5. 首次处理本书时选两页试译：一页普通正文，一页含图表、统计、脚注或复杂排版的代表性页面；没有复杂页时选另一章的正文。对照页面图像检查提取顺序、漏项、术语和数字，再决定是否需要调整提取或翻译方式。把样页页码、发现的问题和处理决定记入 `翻译进度.md`；已有译稿时先检查现有记录，不重复翻译已完成页面。无法可靠读取的内容保持待辨认。

## 分章翻译

- 按原文段落和章节顺序翻译，不概述、跳段或替作者补结论。中文自然流畅，但否定、比较、条件、归属、因果和不确定性不得改变。重要术语首次出现用「中文（English）」；之后按本书术语表统一。
- 保留标题层级、引文、脚注、参考文献、人名、机构名、日期、数字、单位和统计符号。可实现的章/节互引使用稳定的 Markdown/HTML 锚点，并核对目标；不能形成可点链接时保留原文定位信息。
- 简单表格用 Markdown，含合并单元格等复杂结构时用 HTML 表格；逐格核对行列、数值、上标、标题和表注。看不清的单元格明确标记并记入审校记录。图片按本书选定方式处理，图题、图注和图内关键文字另作中文对照；不得把重新绘制的图片冒充原图。
- 只在解决实质歧义或必要背景时加简短译注，并与作者原话区分。心理学概念、研究设计、统计与图表的具体核查点见[审校指南](references/psychology-translation-guide.md)。

## 逐页对照与续译

每章译后先批量扫描疑点：用文本搜索或简短脚本查找术语表中的选定译名及已发现的异译，并定位原文出现该术语的段落，核对对应中文表达；逐页提取原文和译文的阿拉伯数字、百分比、日期、单位及统计符号，比较是否遗漏或改变。排除页眉页码等非正文项目，允许等值的中文表达，但必须回看原页确认。扫描只生成待查项，不自动替换译文，也不能代替逐页对照。把确认的错误及未解决疑点记入 `逐页审校记录.md`，附 PDF 页码和错误类型。

每完成一章，逐页对照 PDF 页面与中文译文，确认该页全部可辨正文和实质内容都已对应。`逐页审校记录.md` 逐页记 PDF 页码、印刷页码（若有）、章节、状态和备注；状态用「未开始／待辨认／待修订／已核对／不适用」。发现问题时另列 PDF 页码、短原文片段、现译、建议译法和错误类型。只修误译、漏译、术语、逻辑、数字、专名与结构错误；不要为润色改写已正确的译文。若发现同一类系统性问题，仅重查受影响章节或页面。

每章结束时更新 `翻译进度.md`：已翻译和已核对的页码范围、术语与数字扫描结果、尚未解决的术语/图表/OCR 问题、下一处起点。只有该章所有应处理页面均「已核对」、扫描疑点已核实且引用、表格和互引可用，才标为完成；否则标为部分完成并说明原因。交付时列出未解决事项和审校覆盖范围。

## 分享边界

此 Skill 不自动上传 PDF、译文、原图或审校摘录。个人翻译可继续；用户提出公开完整译文或原书图表时，提醒其先确认所需授权，不把授权核查设为个人翻译的硬性阻断。
