# 精选心理学术语参考（英→中）

这些中文候选主要从一次心理学教材翻译的工作术语表中筛出，另补少量必要的区分词；提示语重新编写。它们**不是通用标准译名，也不是该教材 Glossary 的译释**。链接用于核对英文概念；个别条目附中文期刊用例，但不代表唯一或官方译名。使用时先查本书定义、研究分支和上下文，再选择译名并记入本书术语表；不合适就改，不可机械替换。

| English | 中文候选 | 适用范围与易混点 | 英文概念核对 |
|---|---|---|---|
| affect | 情感／情绪（名词） | 在心理学术语中看作者定义；作动词时常是「影响」。 | [APA：positive affect](https://dictionary.apa.org/positive-affect) |
| effect | 效应／影响 | 统计结果、研究影响和一般结果须按语境区分；别与 *affect* 混用。 | [APA：effect](https://dictionary.apa.org/effect) |
| evidence-based practice | 循证实践 | 用于临床与应用决策；不等于单纯「有研究支持」。 | [APA：EBP](https://dictionary.apa.org/evidence-based-practice) |
| quantitative research | 定量研究 | 以数量化观察和分析为主；不自动等于实验研究。 | [APA：方法类型](https://www.apa.org/pubs/databases/training/method-values) |
| qualitative research | 定性研究／质性研究 | 两种中文译名都可见；先看本书分支和用语，勿与「质量评估」混淆。 | [APA：方法类型](https://www.apa.org/pubs/databases/training/method-values) |
| meta-analysis | 元分析／荟萃分析 | 指跨研究的统计综合；按学科语境定译名，别把一般综述也写成它。 | [APA：方法类型](https://www.apa.org/pubs/databases/training/method-values)；[《心理科学进展》用例](https://journal.psych.ac.cn/xlkxjz/article/2019/1671-3710/1671-3710-27-3-453.shtml) |
| operationalisation / operationalization | 操作化 | 把概念落实到可观察或可测量方式的过程；*operational definition* 是「操作性定义」。 | [APA：operational definition](https://dictionary.apa.org/operational-definition) |
| sample | 样本 | 实际研究对象；与目标总体区分。 | [APA：random sampling](https://dictionary.apa.org/random-sampling) |
| population | 总体 | 研究希望据以推论的对象范围；不自动等于一般「人口」。 | [APA：random sampling](https://dictionary.apa.org/random-sampling) |
| random sampling | 随机抽样 | 从总体选谁进入样本；与实验条件分派不同。 | [APA：random sampling](https://dictionary.apa.org/random-sampling) |
| random assignment | 随机分派 | 把已纳入研究的单位分到不同条件；与抽样不同。 | [APA：random assignment](https://dictionary.apa.org/random-assignment)；[《心理学报》用例](https://journal.psych.ac.cn/xlxb/article/2018/0439-755X/0439-755X-50-12-1369.shtml) |
| independent variable | 自变量 | 检查作者是否指操纵因素、分组因素或统计预测变量。 | [APA：manipulation](https://dictionary.apa.org/manipulation) |
| dependent variable | 因变量 | 结果或待解释变量；该名称本身不证明因果。 | [APA：dependent variable](https://dictionary.apa.org/dependent-variable) |
| confound / confounding factor | 混淆因素 | 可能使目标因素与其他影响难以分开的因素；按设计描述其作用。 | [APA：confound](https://dictionary.apa.org/confound) |
| experiment | 实验 | 核对操纵、比较条件与分派方法，不凭作者使用此词就补出因果结论。 | [APA：experimental research](https://dictionary.apa.org/experimental-research) |
| correlational study | 相关研究 | 报告变量关联；单凭关联无法决定因果方向。 | [APA：directionality problem](https://dictionary.apa.org/directionality-problem) |
| quasi-experiment | 准实验 | 关注缺少随机分派时因果推论的限制。 | [APA：quasi-experimental design](https://dictionary.apa.org/quasi-experimental-design) |
| reliability | 信度 | 测量一致性；与效度分开写。 | [APA：reliability coefficient](https://dictionary.apa.org/reliability-coefficient)；[《心理科学进展》用例](https://journal.psych.ac.cn/xlkxjz/article/2019/1671-3710/1671-3710-27-7-1194.shtml) |
| validity | 效度 | 先辨明测量效度、内部效度或其他具体类型。 | [APA：internal validity](https://dictionary.apa.org/internal-validity)；[《心理科学进展》用例](https://journal.psych.ac.cn/xlkxjz/article/2019/1671-3710/1671-3710-27-7-1194.shtml) |
| effect size | 效应量 | 描述差异或关联的量级；不等同统计显著性。 | [APA：Cohen's d](https://dictionary.apa.org/cohens-d)；[《心理科学进展》用例](https://journal.psych.ac.cn/xlkxjz/article/2019/1671-3710/1671-3710-27-3-453.shtml) |
| interaction effect | 交互作用 | 一个因素的表现随另一因素水平而异；别泛译为社交互动。 | [APA：two-way ANOVA](https://dictionary.apa.org/two-way-analysis-of-variance) |
| order effect | 顺序效应 | 指条件或题目呈现顺序影响反应。 | [APA：order effect](https://dictionary.apa.org/order-effect) |
| practical significance | 实际意义 | 研究结果的现实用途或影响，与统计显著性分开。 | [APA：practical significance](https://dictionary.apa.org/practical-significance) |

本表故意不收录只在某一本书、某个地区课程制度或某位作者定义下成立的译法。新增词条时写明分支、含义、来源和暂定状态；查证失败的词不要标为权威译名。
